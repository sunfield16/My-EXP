「ディレクトリトラバーサル」とも呼ばれる。  
外部からファイル名やパスを指定してファイルを読み込むような処理があるとき、  
パスに`../`などを含めることで上層のディレクトリにあるファイルにアクセスできてしまう脆弱性。  
絶対パスを指定して`/usr/local/`などにアクセスするパターンもある。

また、ファイルアップロード機能の場合はファイル名をパスのような形にして  
機密ファイルを上書きするケースもある。

## 対策
* パラメータから純粋なファイル名だけ取得する
```php
const LOAD_PATH = "/var/www/app/hoge/data/";

$filepath = $_POST["filepath"];

// basenameでファイル名だけを取得
$filename = basename($filepath);
$file = file_get_contents(LOAD_PATH.$filename);
```
* ↑でrealpathで階層まで合ってるか確認するとより堅い
    - あらかじめ保存先の階層が決まってる場合
```php
const LOAD_PATH = "/var/www/app/hoge/data/";

$realpath = realpath(LOAD_PATH.$filename);
if($realpath === false || strpos($realpath, LOAD_PATH) !== 0)
{
    $file = file_get_contents($realpath);
}
```
